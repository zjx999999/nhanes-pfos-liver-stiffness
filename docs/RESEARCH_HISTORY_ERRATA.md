# Research history and reproducibility errata

Technical revision 1.0.1, prepared on 2026-11-16. Publication status is tracked separately in RELEASE_STATUS.md. The v1.0.0 artifact remains preserved at its original Release URL and SHA-256; a version label here does not assert public availability. No claim is made that a GitHub tag is intrinsically immutable.

1. **Execution evidence:** v1.0.0 preparation verified input hashes and syntax but did not execute its end-to-end model workflow. On 2026-11-16, a subsequent reproduction audit downloaded all 20 CDC files in a new directory and executed the unchanged v1.0.0 runner. That later evidence must not be backdated to initial publication.
2. **Comparison coverage:** the original runner succeeded but compared 16 core CSVs. It deliberately skipped sensitivity_with_probe.csv, a presentation assembly. Version 1.0.1 adds deterministic assembly from regenerated sensitivity_models.csv and probe rows of primary_model_comparison.csv, then compares all 17. No source coefficients are copied from the frozen reference into the assembly.
3. **Independent recalculation:** the historical separate R implementation prints its results and contrast but does not export machine-readable values or automatically fail on a displayed merge difference. Version 1.0.1 appends serialization of already-computed objects and validates four primary-model rows plus the two inference versions of the period contrast. It does not independently cover every secondary model. At the time of that execution audit, these checks were AI-assisted code checks, not a recorded human statistical review. Subsequent author-team review is described below.
4. **Review terminology:** the archived analysis_specification_v1.3.md phrase “Following independent statistical review” refers to historical AI-assisted technical review against official guidance; it must not be interpreted as a signed human statistical review. The archived heading “Prespecified sensitivity analyses” means specifications in a plan finalized after exploratory inspection, not prospective preregistration. The original specification is preserved to retain the actual analysis history; this errata governs its interpretation.
5. **Legacy naming:** the regenerated CSV samala_aligned_2017_unweighted.csv retains the historical note “not exact Eng replication”, and internal R objects use eng_ names. These are legacy attribution labels for the Samala et al. 2024 approximation (doi:10.1093/toxsci/kfae106), not a distinct Eng study or exact replication. They are explained here rather than silently rewriting historical CSV text or numerical values.
6. **Input manifest:** v1.0.0 lists 20 actual input dependencies, including SMQ_J.xpt and SMQ_L.xpt previously absent from the 18-file project manifest. Smoking variables are read but not used in the frozen models. This was a packaging correction, not a change in the clinical adjustment set.
7. **Environment scope:** R 4.5.3/survey 4.5/haven 2.5.5 were run using the existing isolated project R distribution with user/site profiles disabled and separate working outputs. R itself was not freshly rebuilt. A fresh Python virtual environment installed the pinned figure dependencies from the official PyPI index, using cached wheels where available. This is a verified Apple Silicon macOS execution, not a test on every operating system.
8. **Plans, authors and AI:** the finalized plan followed exploratory inspection. The scope of earlier author-reported review, and the current revision approval boundary, are described in AI_USE_AND_AUTHOR_REVIEW.md. The original project code uses the MIT License. The record of actual AI assistance is retained; it is not relabeled as human work or as data processing alone. Repository publication does not constitute an institutional ethics determination.

The study question, data definitions, covariates, weights, model expressions, all frozen CSV values, manuscript scientific conclusions remain unchanged. Author metadata and disclosures have been updated; a subsequent presentation revision adjusts figure geometry and table placement without changing numerical results. This technical revision does not create a new scientific analysis or claim causal identification/equivalence.

9. **Subsequent author-team review:** on 2026-11-17 the project owner confirmed data review by Jiuxi Zhu, manuscript review by Yinlong Zuo, reproducibility review by Yixiao Liu, and reference review by Zhiyi Lin. These are the latest author-reported scopes and supersede earlier imprecise assignments. The confirmation does not establish that authors personally executed all computational steps, does not certify external expert review, and is not backdated to v1.0.0 preparation. Actual AI assistance remains disclosed.
