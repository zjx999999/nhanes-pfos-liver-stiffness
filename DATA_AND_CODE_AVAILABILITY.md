# Data and code availability

NHANES public-use inputs and documentation originate from CDC/NCHS. The 20-input manifest in analysis/reproducibility/ lists official download URLs, sizes and SHA-256. Individual XPT files are not redistributed. data/ contains the 17 frozen aggregate statistical CSVs and ancillary descriptive records.

Source, documentation and IAOEH presentation code are browsable in this repository. The explicit v1.0.1 Release asset is the versioned source archive with its separate SHA-256 file. The v1.0.0 tag and explicit release asset remain historical evidence, with the original hash documented in docs/V1_0_0_ARCHIVE.md. GitHub-generated source archives and explicit release assets are distinct artifacts.

The project owner confirmed review by Jiuxi Zhu (data), Yinlong Zuo (manuscript), Yixiao Liu (reproducibility) and Zhiyi Lin (references). Actual substantive AI use and the timing of these confirmations are described in docs/AI_USE_AND_AUTHOR_REVIEW.md. This is not a claim of external peer review or an institutional ethics determination.
