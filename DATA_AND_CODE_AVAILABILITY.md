# Availability

Original participant-level data and codebooks are available from CDC/NCHS at https://wwwn.cdc.gov/nchs/nhanes/. The analysis/reproducibility/data_manifest.csv lists direct official URLs, byte counts and SHA-256 checksums for all 20 XPT files read by the code. Participant-level files are not redistributed here.

Analysis code, a separate primary-model recalculation script, recorded software versions, frozen aggregate outputs and figure-generation code are available at https://github.com/zjx999999/nhanes-pfos-liver-stiffness. Cite the actual release/tag or commit when using these materials. This is a GitHub archive, not an assigned DOI, and does not establish independent human review, author approval or institutional ethics determination.

The complete material is distributed as the versioned ZIP file in this repository; its directory structure is preserved inside the archive.
