# Data and code availability

NHANES public-use inputs and documentation originate from CDC/NCHS. The 20-input manifest in analysis/reproducibility/ lists official download URLs, sizes and SHA-256. Individual XPT files are not redistributed. data/ contains the 17 frozen aggregate statistical CSVs and ancillary descriptive records.

Source, documentation and IAOEH presentation code are browsable in this repository. The versioned v1.0.2 source archive and its separate SHA-256 file are available at https://github.com/zjx999999/nhanes-pfos-liver-stiffness/releases/tag/v1.0.2. The v1.0.0 and v1.0.1 tags and explicit release assets remain preserved. GitHub-generated source archives and explicit release assets are distinct artifacts.
